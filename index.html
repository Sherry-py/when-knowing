A decade of multi-stakeholder climate-governance work — building MRV (Measurement, Reporting, Verification) systems trusted by regulators, SOEs, and the UNFCCC secretariat — produced a single methodological commitment: reliable system behavior is a structural property of the action channel, not an event at decision moments. GateFix ports that MRV lineage into AI execution: the same measure → report → verify discipline, re-instantiated as a commit-point gate for agentic systems. Continuous Governance Architecture generalizes it into a three-party symbiotic architecture (LLM + methodology + human).

十年的多方气候治理实践 —— 搭建被监管方、国企、UNFCCC 秘书处信任的 MRV（可测量、可报告、可核查）体系 —— 得出一个方法论承诺：可靠的系统行为是行动通道本身的结构属性，而非决策时刻的事件。GateFix 把这条 MRV 血统迁移进 AI 执行治理：同一套"测量 → 报告 → 核查"的纪律，重新落地为 agentic 系统的 commit-point 授权门。连续治理架构（Continuous Governance Architecture）则把它推广为 LLM + 方法论 + 人三方共生的架构。

I design cognitive scaffolding for agentic AI systems — structural validation continuously, commit-point attestation at boundaries. Its lineage runs from a decade of climate-MRV governance practice to AI execution, and now toward embodied AI and industrial deployment — where an unrecoverable action carries the highest stakes. The checkpoint before an agent commits

Agent 动手之前的那道关卡

Today's AI agents don't just answer questions — they act: send emails, move money, delete files, ship packages. The problem is some actions can't be undone once they happen. GateFix is the check that runs right before the agent pulls the trigger: is it qualified to do this, right now? Has it actually thought it through?

今天的 AI agent 不只是回答问题，它能自己动手做事——发邮件、转账、删文件、把东西寄出去。问题是：有些动作一旦做了就收不回来。GateFix 是在 agent 真正扣扳机的那一刻之前的一道检查：它现在够不够格做这件事？想清楚了吗？

Real-world scenario · Medical automation

现实场景 · 医疗自动化

A bedside nurse needs to sedate a patient before a scan. The ordered drug isn't indexed under its brand name, so the cabinet search comes up empty. The nurse triggers an override — which opens a much wider drug range — searches again, and the cabinet offers a different, high-alert drug.

床边护士需要在检查前给患者用镇静剂。医嘱药品在自动配药柜（ADC）里没有按商品名收录，搜索落空。护士触发 override——打开了远超当前医嘱范围的药品库——再次搜索，柜子这次给出了一个完全不同的高警示药品。

Most people are working on making agents smarter — better diagnosis. GateFix works on the layer in between: execution authorization. Same action — pass it when context is sufficient, repair, escalate, or hand it to a human when it isn't. This doesn't limit what the agent can do; it gives it a brake on irreversible actions, so it can actually be trusted to act on its own.

大多数人在让 agent 更聪明（诊断得更准）；GateFix 做的是中间那层——执行授权：同一个动作，上下文够就放行，不够就修复、上报或转人工。不是限制 agent 的能力，是让它在不可逆的动作上有一道刹车，从而能真正放手去干。

Mechanism: work backward from the irreversible commit point to its preconditions → four-state disposition (PASS / AUTO_REPAIR / ESCALATE / BYPASS_TO_HUMAN).

机制：从不可逆的 commit point 反向推导前置条件 → 四态处置（PASS / AUTO_REPAIR / ESCALATE / BYPASS_TO_HUMAN）。

Stream 04 · Continuous Governance Architecture · A symbiotic architecture for human–LLM–methodology systems · In progress

Reliable governance is a structural property of the action channel, not an event at decision moments. Current AI safety architectures govern at the platform layer (model providers, API guardrails); the deploying organization absorbs the residual — a mismatch between governance locus and accountability locus.

可靠的治理是行动通道本身的结构属性，而非决策时刻的事件。当前 AI 安全架构治理停留在平台层（模型提供方、API 护栏）；部署方组织承担一切残余风险 —— 治理归属与问责归属在结构上错位。

Continuous Governance Architecture composes closed-loop authorization harnesses (continuous-time self-correction, à la Paper 1) with commit points (discrete-time boundary attestation; Weill & Ross, 2004). Requisite-variety reasoning (Ashby, 1956) makes both layers necessary: platform-layer guardrails cannot match the environmental variety of agentic action.

连续治理架构由两层组合而成：闭环授权 harness（连续时间的自校正，沿用 Paper 1）与 commit point（离散时间的边界证 attestation；Weill & Ross, 2004）。按 requisite-variety 原理（Ashby, 1956），平台层护栏的控制变量无法匹配 agentic 行动的环境变量。

Position
立场

Cybernetics, re-instantiated.

控制论的再具身

The problem of the agent era is not new in form — it is the problem Wiener (1948) identified at the birth of cybernetics: perception decoupled from action. What changes is the sensor. In classical control systems the sensor is external to the controlled object. In agentic systems the sensor is the agent's own diagnostic self-report. This is the formally novel piece, and the reason a two-layer architecture — closed-loop harness with commit-point attestation — is required.

Agent 时代的问题在形式上并不新 —— 它正是 Wiener (1948) 在控制论诞生时指认的：感知与行动的解耦。变化在于传感器。经典控制系统中，传感器外在于被控对象；agentic 系统中，传感器就是 agent 自己的诊断自报。这是形式上真正新的部分，也是为什么需要双层架构 —— 闭环 harness 加 commit-point 证明。

That is also the specific intersection UNSW ISTM works in: principal-agent theory, design science, and behavioural experiments on how humans actually operate these gates.

这也正是 UNSW ISTM 所处的研究交汇点：委托代理理论、设计科学，以及"人类如何实际操作这些 gate"的行为实验。
